Prudent — Your Wealth's Co-Pilot

Prudent is a student-focused personal finance and expense intelligence web application designed to help college students and Gen-Z users track expenses, manage budgets, understand spending habits, and build healthier financial habits.

The goal is to make personal finance simple, visual, and accessible through a modern, colorful, and responsive user interface.

Features:

1. 📊 Interactive Dashboard — Get an overview of your balance, income, expenses, and savings.
2. 💸 Transaction Management — View and organize income and expenses by category.
3. 🎯 Budget Tracking — Monitor spending against monthly category budgets.
4. 📈 Analytics & Insights — Visualize spending patterns and understand where your money goes.
5. 💰 Savings Goals — Track progress toward personal financial goals.
6. 🌗 Dark & Light Mode — Switch between themes for a comfortable viewing experience.
7. 📱 Responsive Design — Designed to work across desktops, tablets, and mobile devices.
8. 🔐 Authentication UI — Includes login and sign-up screens.

🛠️ Tech Stack:

1. HTML5 — Page structure and semantic markup
2. CSS3 — Styling, responsive layouts, and themes
3. JavaScript (Vanilla) — Interactive components and client-side functionality

🎨 Design Philosophy:

Prudent combines the simplicity of a student productivity app with the visual clarity of a modern fintech dashboard.

The interface uses a consistent design system with:

1. Purple as the primary brand color
2. Semantic colors for income, expenses, savings, and warnings
3. Clean typography and reusable UI components
4. Data visualizations and intuitive navigation
5. Responsive layouts for different screen sizes

🚀 Getting Started:

1. Clone the repository

git clone https://github.com/shandilyasakshi/Prudent_front-end_project

2. Open the project folder

Current Project Status:

Prudent is currently a frontend-focused project built with HTML, CSS, and Vanilla JavaScript.

The login and sign-up screens provide the authentication interface, but real user authentication and account management require a backend or authentication service.

Database integration, secure authentication, and persistent user-specific financial data are not included in the current frontend-only version.

🔮 Future Improvements:

1. Integrate Supabase or Firebase for authentication and data storage.
2. Implement secure user sessions and protected dashboard routes.
3. Add persistent transaction and budget management.
4. Develop personalized financial insights.
5. Improve accessibility and form validation.
6. Add automated testing and deploy the application.
